プライバシーポリシー

アントログ（以下「本アプリ」）の、利用者の情報の取り扱いについて説明します。
施行日：2026年11月12日（2026年11月14日 改定：トラッキングをやめ、パーソナライズされない広告だけにしました）

1. 本アプリが集める情報

本アプリは、利用者の名前・メールアドレス・電話番号などの個人を特定する情報を集めません。アカウントの登録もありません。

遊んだ記録（巣の状態、年表、実績、設定、広告で受け取った回数など）は、利用者の端末の中にだけ保存し、開発者を含め外部に送信しません。本アプリを削除すると、これらの記録も削除されます。

2. 広告の配信のために送られる情報

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を利用し、パーソナライズされない広告（利用者の過去の行動や興味に基づかない広告）だけを表示します。本アプリはトラッキング（本アプリで集めた情報を、他社のアプリやウェブサイトで集められた情報と結び付けて、広告や広告の測定に使うこと）を行いません。そのため、端末の広告識別子（IDFA）を使う許可もおたずねしません。

広告を表示するため、AdMob の SDK が次の情報を自動的に収集し、Google に送信することがあります。

  • アプリや開発者ごとの識別子など、端末の識別子
  • IP アドレスから推定されるおおよその位置
  • 表示された広告や、広告への操作などの使用状況
  • アプリのクラッシュやパフォーマンスに関する情報

パーソナライズされない広告でも、同じ広告の表示回数の制限や、広告の集計、不正の防止のために、これらの情報が使われることがあります。これらの情報の取り扱いは、Google のプライバシーポリシーに従います。

  • Google のプライバシーポリシー
  • Google のパートナーのサイトやアプリでのデータの使用

3. 広告のための情報の利用への同意

欧州経済領域・英国など、法令により同意が必要な地域では、Google の同意の仕組み（User Messaging Platform）による画面で、広告のための情報の利用に同意するかどうかを選べます。

4. 子どもの利用について

本アプリは、子どもを主な対象としたアプリではありません。13歳未満の子どもから意図して情報を集めることはありません。

内容を変更する場合は、このページでお知らせします。
